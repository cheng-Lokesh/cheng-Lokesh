## 代表项目

### [Astraloom｜证据链驱动的多智能体情景模拟](https://github.com/cheng-Lokesh/Astraloom)

把复杂现实处境转化为关键人物、Agent Profile、关系图谱与事件序列，并让重要结论能够回溯到证据。项目重点不是“预测命运”，而是构建一个能表达不确定性、支持复盘的决策观察系统。

`Next.js` `TypeScript` `Supabase` `Multi-Agent` `Knowledge Graph` `Explainable AI`

### [缓冲区｜空窗期生存操作系统](https://github.com/cheng-Lokesh/buffer)

面向待业、转型和项目空窗期，把现金流、求职进度、项目投入与每日行动放进同一套个人执行系统。覆盖响应式 Web、微信小程序、本地数据和服务端权益边界。

`React` `Vite` `微信小程序` `Cloudflare Workers` `Product Design`

### [TradeSniper｜二手商品智能监控工具](https://github.com/cheng-Lokesh/tradesniper)

通过浏览器自动化、规则过滤和 AI 辅助分析，减少二手平台商品筛选中的重复劳动，并用桌面界面呈现监控与候选结果。

`Python` `Playwright` `Tkinter` `Automation` `LLM`

### [星夜伴侣｜多角色 AI 聊天应用](https://github.com/cheng-Lokesh/StarNight_Companion)

支持多角色人设、场景上下文、语音合成、本地会话记忆和主题切换的 AI 聊天产品原型，探索角色一致性与沉浸式交互体验。

`Next.js` `React` `TypeScript` `Zustand` `TTS`

## 我的工作方式

- 先定义真实问题、用户价值与不能越过的边界，再决定技术方案。
- 把模型输出放入结构化数据和可追溯流程，而不是让生成文本成为唯一真相。
- 同时考虑桌面端、移动端、异常路径、数据安全和后续迭代成本。
- 用测试、真实浏览器和服务端状态验证结果，区分“代码存在”和“产品成立”。
