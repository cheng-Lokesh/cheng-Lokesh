## Buffer · 缓冲区
**个人现金状态与未来模拟工具｜Web / 微信小程序**

收入不稳定时，仅看当前余额很难理解未来压力。Buffer 将当前现金、持续收支和已知事项组织成可解释的未来轨迹，让用户看清现实，并比较不同条件下的变化。

**产品设计与实现**

- 以“现在、未来、条件、记录”四个空间组织信息，把状态查看、未来推演、条件维护与变化复盘串成完整流程。
- 展示 30 / 60 / 90 天现金轨迹，支持具体日期与余额查找，将图形转化为可以查询、解释的信息。
- 设计组合情景试算，支持叠加一次及周期收支、调整金额和暂停条件，比较多项变化共同产生的影响。
- 将自然语言输入组织为“理解、核对、确认”的交互流程，在降低输入负担的同时保留用户对真实数据的控制。
- 将现实、预测与模拟分开处理，并通过共享计算规则推进网页版与微信小程序的一致性。

**体现的能力：** 复杂需求收敛、信息架构、可视化交互、AI 能力边界设计、多端产品迭代。

**项目技术：** JavaScript / Node.js · 微信小程序 · LLM 结构化解析 · CloudBase / PostgreSQL · EdgeOne

[查看项目与实现 →](https://github.com/cheng-Lokesh/buffer)

## Astraloom
**证据链驱动的多智能体情景模拟**

<a href="https://github.com/cheng-Lokesh/Astraloom">

</a>

面对关系、职业和家庭等复杂处境，普通 AI 回答往往难以解释结论的来源。Astraloom 将现实材料整理为人物档案、关系图谱与事件序列，让模拟过程和结论具有可检查的依据。

**产品设计与实现**

- 组织现实输入、信息澄清、关键人物、关系图谱、模拟运行与反馈的连续产品流程。
- 以角色档案和关系图谱表达支持、压力与冲突，使用确认后的图谱快照作为模拟输入。
- 将重要结论关联到具体事件，设计从结果回溯过程的证据链。
- 在系统设计中区分事实、推断与未知信息，并纳入账户数据隔离和高风险场景处理。

**体现的能力：** AI 原生产品设计、复杂流程建模、多智能体协作、可解释性与数据安全意识。

**项目技术：** Next.js · React · TypeScript · Supabase · React Flow · Three.js

[查看项目与实现 →](https://github.com/cheng-Lokesh/Astraloom)

## TradeSniper
**二手商品自动化监控与 AI 辅助筛选｜桌面原型**

二手商品筛选需要反复搜索，同时受到重复信息和商家内容干扰。TradeSniper 将关键词巡检、规则过滤、语义分析与候选展示连接成一条自动化流程。

**产品设计与实现**

- 根据关键词和价格区间巡检商品，维护浏览器登录会话。
- 先以卖家、库存和价格规则筛选，再调用 AI 分析候选描述并补充排序理由。
- 通过桌面监控面板展示日志、过滤过程与候选结果，保留人工判断环节。

**体现的能力：** 场景拆解、自动化产品设计、规则与模型组合、运行过程可视化。

**项目技术：** Python · Playwright · Tkinter · DeepSeek API

[查看项目与实现 →](https://github.com/cheng-Lokesh/tradesniper)

## 星夜伴侣 · StarNight Companion
**多角色、场景化 AI 聊天｜Web 原型**

<a href="https://github.com/cheng-Lokesh/StarNight_Companion">
  <img src="https://raw.githubusercontent.com/cheng-Lokesh/StarNight_Companion/main/docs/assets/starnight-overview.png" alt="星夜伴侣多角色聊天界面" width="100%">

围绕角色一致性和连续对话体验，将角色设定、场景上下文、独立会话记忆与语音能力组合成可操作的聊天产品。

**产品设计与实现**

- 分别维护角色会话与本地记忆，支持历史恢复、多会话管理和文本导出。
- 整合对话、语音合成、情绪反馈与主题切换，处理移动端及异步交互体验。

**体现的能力：** 对话体验设计、上下文编排、状态管理、多模态交互与响应式设计。
